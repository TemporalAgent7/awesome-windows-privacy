## Reporting a Vulnerability

To report a vulnerability, please follow these steps:

1. **Submit a Report**: Report the vulnerability by sending a direct message with detailed information to [@ArkoTest on Twitter/X](https://x.com/arkotest). Please include steps to reproduce the issue, potential impact, and any other relevant details.

2. **Acknowledgment**: An acknowledgment of your report will be sent within 48 hours.

3. **Resolution Timeline**: A resolution or status update on the reported vulnerability will be provided within 14 days. Critical issues may be addressed sooner.

4. **Feedback**: If the vulnerability is confirmed, you will be informed about the fix and any necessary mitigation steps. If not accepted, you will receive an explanation.

5. **Disclosure**: Public disclosure of the vulnerability will only occur after a fix has been released or sufficient time has passed for users to update to the latest version.

Thank you for contributing to the security of this project!
