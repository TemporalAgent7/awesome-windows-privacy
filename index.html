Awesome Windows Privacy

A curated list of essential tools, documentation, and scripts to enhance privacy on Microsoft Windows.

Disclaimer

This repository is a modified version of the main awesome-windows-privacy repo created by TemporalAgent7. I have reviewed and updated each link to ensure its accuracy and relevance. Additionally, I have included additional tools to further improve privacy. I hope you'll find this resource useful.

Sections

Powershell and Batch Scripts

  • TronScript - A collection of scripts designed to automate the cleanup and disinfection of Windows computers.
    Important: Reboot your system before running Tron to avoid potential issues.
  • Blackbird - A lightweight tool aimed at removing Windows spyware and blocking tracking services without needing a graphical interface.
  • Sophia Script for Windows - A powerful PowerShell module for fine-tuning and tweaking Windows 10 & 11.
  • Optimize Offline - A framework for offline optimization of Windows 10 images.
  • Windows 10 Bloat Remover and Tweaker - A configurable CLI tool for debloating and tweaking Windows 10 by removing preinstalled UWP apps, services, and more.
  • Windows On Reins - A PowerShell script designed to harden, debloat, optimize, enhance privacy, and improve performance on Windows 10 and 11.
  • PowerShell scripts for Windows 10 - A PowerShell script focused on privacy settings for Windows 10.
  • Windows10Tools - Tools designed for Windows 10.
  • Windows-Optimize-Debloat - Tools for minimizing Windows 10 installations.
  • windows-settings - Scripts and configurations for hardening Windows 10.
  • Windows 10 Privacy and Control Enhance - A PowerShell script for configuring the highest privacy and control settings in Windows 10.
  • Windows 10 Privacy Fixup - Tools for addressing Windows 10 bloat and privacy issues.
  • windows10-debloat - A collection of scripts and applications to debloat Windows 10, improving privacy, performance, and optimization.
  • BetterPrivacy - A PowerShell script designed to enhance privacy on Windows 10.
  • Windows 10 batch optimizer - A tool for optimizing Windows 10 for performance, privacy, and security.
  • Private Secure Windows - A baseline for ensuring privacy and security on Windows 10 and 11.
  • DoNotSpy11 - An application that simplifies the configuration of privacy settings in Windows 10 and 11.
  • tiny11builder - Scripts for creating a streamlined Windows 11 image.

OSS Applications

  • Privatezilla - Performs a privacy and security check on Windows 10.
  • WindowsSpyBlocker - Blocks spying and tracking on Windows.
  • privacy.sexy - An open-source tool to enforce privacy and security best practices on Windows and macOS.
  • WinSlap - Quickly configures a fresh Windows 10 installation with useful tweaks and anti-spy settings.
  • Chemo - Removes pre-installed junk from Windows 10.
  • Windows10Privacy - Simplifies permissions settings and advanced controls for Windows 10 (compatible with version 1809).
  • winutil - A utility by Chris Titus Tech for installing programs, applying tweaks, and performing fixes and updates.

Documentation

  • Windows 10_Anti Telemetry - A guide for mitigating telemetry in Windows 10 x64.
  • The Privacy Project - Offers guides and resources for maintaining privacy online.
  • PrivacyTools.io - Provides recommendations for privacy-focused tools and services.
  • The Privacy Guide - A resource for learning about privacy and the tools to help protect it.
  • Electronic Frontier Foundation (EFF) - An organization defending civil liberties in the digital world.
  • SecureDrop - A whistleblower submission system that media organizations can use to securely accept documents from anonymous sources.
  • No More Ransom - A collaboration between law enforcement and IT security companies to combat ransomware.

Misc

  • windows10.dns.list - DNS list for blocking various elements in Windows 10.
  • Batch Audio Converter - A simple utility for converting audio files in batch.
  • Tiny10 - A minimal version of Windows 10.

Non-OSS Applications

  • O&O ShutUp10++ - A free tool for managing privacy settings in Windows 10 and 11.
  • W10Privacy - A Windows tool for modifying privacy-related settings.
  • Abelssoft Windows Privacy Control - Protects against Windows 10 & 11 telemetry and unwanted updates.
  • Abelssoft Sync Manager - A program that lets you synchronize data between different devices and services.
  • IObit Uninstaller - Uninstalls programs and browser plug-ins, and cleans up remnants of programs.
