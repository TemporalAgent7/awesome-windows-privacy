Awesome Windows Privacy

A list of awesome tools, documentation, and scripts for better privacy on Microsoft Windows

Powershell and Batch Scripts

  • TronScript - Tron is a collection of scripts designed to automate the cleanup and disinfection of Windows computers.
  • Blackbird - A lightweight tool that aims to remove Windows spyware and block tracking services without requiring a graphical interface.
  • Sophia Script for Windows - The most powerful PowerShell module on GitHub for Windows 10 & Windows 11 fine-tuning and tweaking.
  • Optimize Offline - Optimize-Offline is a Windows 10 offline image optimization framework.
  • Windows 10 Bloat Remover and Tweaker - Configurable CLI tool to easily and aggressively debloat and tweak Windows 10.

OSS Applications

  • Privatezilla - Performs a privacy & security check of Windows 10.
  • WindowsSpyBlocker - Block spying and tracking on Windows.
  • privacy.sexy - Open-source tool to enforce privacy & security best-practices on Windows and macOS.

Documentation

  • Windows 10_Anti Telemetry - My anti-telemetry guide for Windows 10 x64.

Misc

  • windows10.dns.list - Block everything Windows 10.

Non-OSS Applications

  • O&O ShutUp10++ - Free antispy tool for Windows 10 and 11.
  • O&O AppBuster - Bust Apps you do not want (uninstall store applications and packages).
