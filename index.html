Awesome Windows Privacy

A list of awesome tools, documentation, and scripts for better privacy on Microsoft Windows

Powershell and Batch Scripts

  • TronScript - Tron is a collection of scripts designed to automate the cleanup and disinfection of Windows computers.
  • Blackbird - A lightweight tool that aims to remove Windows spyware and block tracking services without requiring a graphical interface.
  • Sophia Script for Windows - The most powerful PowerShell module on GitHub for Windows 10 & Windows 11 fine-tuning and tweaking.
  • Optimize Offline - Optimize-Offline is a Windows 10 offline image optimization framework.
  • Windows 10 Bloat Remover and Tweaker - Configurable CLI tool to easily and aggressively debloat and tweak Windows 10 by removing preinstalled UWP apps, services, and more.
  • Windows On Reins - Wor is a Powershell script to harden, debloat, optimize, enhance privacy, avoid fingerprinting, and improve performance on Windows 10 and 11.
  • PowerShell scripts for Windows 10 - PowerShell script for Windows 10 privacy settings.
  • Windows10Tools - Tools for Windows 10.
  • Windows-Optimize-Debloat - For those who seek to minimize their Windows 10 installs.
  • windows-settings - Windows 10 hardening scripts and configs.
  • Windows 10 Privacy and Control Enhance - A PowerShell script to automatically configure for the highest privacy and control settings in Windows 10.
  • Windows 10 Privacy Fixup - Fixes and neuters the Windows 10 bloat and privacy violations so it can be finally usable.
  • windows10-debloat - Collection of various scripts and apps to debloat Windows 10 for better privacy, performance, and optimization.
  • BetterPrivacy - PowerShell script to improve your privacy on Windows 10 computers.
  • Windows 10 batch optimizer - Autotuner Windows 10 for awesome performance settings, privacy, and security.
  • Private Secure Windows - Privacy and security baseline for personal Windows 10 and Windows 11.
  • DoNotSpy11 - An application to easily configure privacy settings in Windows 10 and 11, providing control over telemetry and other invasive settings.
  • tiny11builder - Scripts to build a trimmed-down Windows 11 image.

OSS Applications

  • Privatezilla - Performs a privacy & security check of Windows 10.
  • WindowsSpyBlocker - Block spying and tracking on Windows.
  • privacy.sexy - Open-source tool to enforce privacy & security best-practices on Windows and macOS.
  • WinSlap - Swiftly configure a fresh Windows 10 installation with useful tweaks and antispy settings.
  • Chemo - Remove pre-installed junk from Windows 10.
  • Windows10Privacy - Streamlines permissions settings and advanced controls for Windows 10 (built for version 1809).
  • winutil - Chris Titus Tech's Windows Utility - Install Programs, Tweaks, Fixes, and Updates.

Documentation

  • Windows 10_Anti Telemetry - My anti-telemetry guide for Windows 10 x64.

Misc

  • windows10.dns.list - Block everything Windows 10.

Non-OSS Applications

  • O&O ShutUp10++ - Free antispy tool for Windows 10 and 11.
  • O&O AppBuster - Bust Apps you do not want (uninstall store applications and packages).
  • WinReducer-EX - Remove components from WIM/ISO.
  • MSMG ToolKit - Creates a slimmed down or bloat-free Windows by customizing, adding, or removing features and components.
  • NTLite - Integrate updates, drivers, and remove Windows components from Windows ISO or live installation.
  • Winaero Tweaker - All-in-one app for tuning Windows {7, 8, 10, 11}.
  • WPD - Convenient way to configure various privacy settings in Windows.
