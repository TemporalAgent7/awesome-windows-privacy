# Awesome Windows Privacy A curated list of essential tools, documentation, and scripts to enhance privacy on Microsoft Windows. ## Disclaimer This repository is a modified version of the main [awesome-windows-privacy repo](https://github.com/TemporalAgent7/awesome-windows-privacy) created by TemporalAgent7. I have reviewed and updated each link to ensure its accuracy and relevance. Additionally, I have included additional tools to further improve privacy. I hope you'll find this resource useful. ## Sections ### Powershell and Batch Scripts - [TronScript](https://bmrf.org/repos/tron/) - A collection of scripts designed to automate the cleanup and disinfection of Windows computers. **Important**: Reboot your system before running Tron to avoid potential issues. - [Blackbird](https://www.getblackbird.net/) - A lightweight tool aimed at removing Windows spyware and blocking tracking services without needing a graphical interface. - [Sophia Script for Windows](https://github.com/farag2/Sophia-Script-for-Windows) - A powerful PowerShell module for fine-tuning and tweaking Windows 10 & 11. - [Optimize Offline](https://github.com/DrEmpiricism/Optimize-Offline) - A framework for offline optimization of Windows 10 images. - [Windows 10 Bloat Remover and Tweaker](https://github.com/Fs00/Win10BloatRemover) - A configurable CLI tool for debloating and tweaking Windows 10 by removing preinstalled UWP apps, services, and more. - [Windows On Reins](https://github.com/gordonbay/Windows-On-Reins) - A PowerShell script designed to harden, debloat, optimize, enhance privacy, and improve performance on Windows 10 and 11. - [PowerShell scripts for Windows 10](https://github.com/MichiMunich/Windows10-Privacy) - A PowerShell script focused on privacy settings for Windows 10. - [Windows10Tools](https://github.com/L33Tech/Windows10Tools) - Tools designed for Windows 10. - [Windows-Optimize-Debloat](https://github.com/simeononsecurity/Windows-Optimize-Debloat) - Tools for minimizing Windows 10 installations. - [windows-settings](https://github.com/milgradesec/windows-settings) - Scripts and configurations for hardening Windows 10. - [Windows 10 Privacy and Control Enhance](https://github.com/RedAndBlueEraser/windows-10-enhance-2) - A PowerShell script for configuring the highest privacy and control settings in Windows 10. - [Windows 10 Privacy Fixup](https://github.com/iDigitalFlame/Windows10Fixup) - Tools for addressing Windows 10 bloat and privacy issues. - [windows10-debloat](https://github.com/Daksh777/windows10-debloat) - A collection of scripts and applications to debloat Windows 10, improving privacy, performance, and optimization. - [BetterPrivacy](https://github.com/hulr/BetterPrivacy) - A PowerShell script designed to enhance privacy on Windows 10. - [Windows 10 batch optimizer](https://github.com/SeregaSPb/Windows-10-batch-optimizer) - A tool for optimizing Windows 10 for performance, privacy, and security. - [Private Secure Windows](https://github.com/troennes/private-secure-windows) - A baseline for ensuring privacy and security on Windows 10 and 11. - [DoNotSpy11](https://pxc-coding.com/donotspy11/) - An application that simplifies the configuration of privacy settings in Windows 10 and 11. - [tiny11builder](https://github.com/ntdevlabs/tiny11builder) - Scripts for creating a streamlined Windows 11 image. ### OSS Applications - [Privatezilla](https://github.com/builtbybel/privatezilla) - Performs a privacy and security check on Windows 10. - A utility by Chris Titus Tech for installing programs, applying tweaks, and performing fixes and updates. ### Documentation - [Windows 10_Anti Telemetry](https://github.com/beerisgood/Windows10_Anti-Telemetry) -
