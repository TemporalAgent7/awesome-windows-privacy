## Powershell and Batch Scripts 🚀
*Collection of PowerShell or batch scripts that automate disabling services, registry keys, and scheduled tasks.*

- [TronScript](https://bmrf.org/repos/tron/) - A collection of scripts designed to automate the cleanup and disinfection of Windows computers. **Important**: Reboot before running Tron to avoid bricking your system.
- [Blackbird](https://www.getblackbird.net/) - A lightweight tool that removes Windows spyware and blocks tracking services.
- [Sophia Script for Windows](https://github.com/farag2/Sophia-Script-for-Windows) - A powerful PowerShell module for Windows 10 & 11 fine-tuning and tweaking.
- [Optimize Offline](https://github.com/DrEmpiricism/Optimize-Offline) - A Windows 10 offline image optimization framework.
- [Windows 10 Bloat Remover and Tweaker](https://github.com/Fs00/Win10BloatRemover) - A CLI tool to debloat and tweak Windows 10 by removing preinstalled UWP apps, services, and more.
- [Windows On Reins](https://github.com/gordonbay/Windows-On-Reins) - A script to harden, debloat, optimize, and enhance privacy on Windows 10 and 11.
- [PowerShell scripts for Windows 10](https://github.com/MichiMunich/Windows10-Privacy) - Privacy settings for Windows 10.
- [Windows10Tools](https://github.com/L33Tech/Windows10Tools) - Tools for Windows 10.
- [Windows-Optimize-Debloat](https://github.com/simeononsecurity/Windows-Optimize-Debloat) - Minimizes Windows 10 installs.
- [windows-settings](https://github.com/milgradesec/windows-settings) - Windows 10 hardening scripts and configs.
- [Windows 10 Privacy and Control Enhance](https://github.com/RedAndBlueEraser/windows-10-enhance-2) - Automates the configuration for the highest privacy and control settings in Windows 10.
- [Windows 10 Privacy Fixup](https://github.com/iDigitalFlame/Windows10Fixup) - Fixes Windows 10 bloat and privacy violations.
- [windows10-debloat](https://github.com/Daksh777/windows10-debloat) - Collection of scripts and apps to debloat Windows 10.
- [BetterPrivacy](https://github.com/hulr/BetterPrivacy) - Improves privacy on Windows 10.
- [Windows 10 batch optimizer](https://github.com/SeregaSPb/Windows-10-batch-optimizer) - Autotuner for performance, privacy, and security.
- [Private Secure Windows](https://github.com/troennes/private-secure-windows) - Privacy and security baseline for Windows 10 and 11.
- [DoNotSpy11](https://pxc-coding.com/donotspy11/) - Configures privacy settings in Windows 10 and 11.
- [Win11Debloat](https://github.com/Daksh777/win11debloat) - Removes Windows bloatware, disables telemetry, and cleans up the interface.
- [tiny11builder](https://github.com/ntdevlabs/tiny11builder) - Builds a trimmed-down Windows 11 image.

## OSS Applications 🔧
*UI tools that automate debloating Windows.*

- [Privatezilla](https://github.com/builtbybel/privatezilla) - Performs a privacy & security check of Windows 10.
- [WindowsSpyBlocker](https://github.com/crazy-max/WindowsSpyBlocker) - Blocks spying and tracking on Windows.
- [privacy.sexy](https://github.com/undergroundwires/privacy.sexy) - Enforces privacy & security best practices on Windows and macOS.
- [WinSlap](https://github.com/svenmauch/WinSlap) - Configures a fresh Windows 10 installation with useful tweaks and antispy settings.
- [Chemo](https://github.com/t-richards/chemo) - Removes pre-installed junk from Windows 10.
- [Windows10Privacy](https://github.com/ConditionalException/Windows10Privacy) - Streamlines permissions settings and advanced controls for Windows 10.
- [winutil](https://github.com/ChrisTitusTech/winutil) - Chris Titus Tech's Windows Utility for installing programs, tweaks, fixes, and updates.

## Non-OSS Applications 🛡️
*Non-open source (not free) applications for debloating Windows.*

- [O&O ShutUp10++](https://www.oo-software.com/en/shutup10) - Free antispy tool for Windows 10 and 11.
- [O&O AppBuster](https://www.oo-software.com/en/ooappbuster) - Uninstalls store applications and packages.
- [WinReducer-EX](https://www.winreducer.net/) - Removes components from WIM/ISO.
- [MSMG ToolKit](https://m.majorgeeks.com/files/details/msmg_toolkit.html) - Creates a slimmed-down or bloat-free Windows by customizing features.
- [NTLite](https://www.ntlite.com/) - Integrates updates, drivers, and removes Windows components from ISO or live installation.
- [Winaero Tweaker](https://winaerotweaker.com/) - All-in-one app for tuning Windows 7, 8, 10, and 11.
- [WPD](https://wpd.app/) - Configures various privacy settings in Windows.
