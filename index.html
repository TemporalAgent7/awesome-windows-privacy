Powershell and Batch Scripts 🚀

  • TronScript - A collection of scripts designed to automate the cleanup and disinfection of Windows computers. Important: Reboot before running Tron to avoid bricking your system.
  • Blackbird - A lightweight tool that removes Windows spyware and blocks tracking services.
  • Sophia Script for Windows - A powerful PowerShell module for Windows 10 & 11 fine-tuning and tweaking.
  • Optimize Offline - A Windows 10 offline image optimization framework.
  • Windows 10 Bloat Remover and Tweaker - A CLI tool to debloat and tweak Windows 10 by removing preinstalled UWP apps, services, and more.
  • Windows On Reins - A script to harden, debloat, optimize, and enhance privacy on Windows 10 and 11.
  • PowerShell scripts for Windows 10 - Privacy settings for Windows 10.
  • Windows10Tools - Tools for Windows 10.
  • Windows-Optimize-Debloat - Minimizes Windows 10 installs.
  • windows-settings - Windows 10 hardening scripts and configs.
  • Windows 10 Privacy and Control Enhance - Automates the configuration for the highest privacy and control settings in Windows 10.
  • Windows 10 Privacy Fixup - Fixes Windows 10 bloat and privacy violations.
  • windows10-debloat - Collection of scripts and apps to debloat Windows 10.
  • BetterPrivacy - Improves privacy on Windows 10.
  • Windows 10 batch optimizer - Autotuner for performance, privacy, and security.
  • Private Secure Windows - Privacy and security baseline for Windows 10 and 11.
  • DoNotSpy11 - Configures privacy settings in Windows 10 and 11.
  • Win11Debloat - Removes Windows bloatware, disables telemetry, and cleans up the interface.
  • tiny11builder - Builds a trimmed-down Windows 11 image.

OSS Applications 🔧

  • Privatezilla - Performs a privacy & security check of Windows 10.
  • WindowsSpyBlocker - Blocks spying and tracking on Windows.
  • privacy.sexy - Enforces privacy & security best practices on Windows and macOS.
  • WinSlap - Configures a fresh Windows 10 installation with useful tweaks and antispy settings.
  • Chemo - Removes pre-installed junk from Windows 10.
  • Windows10Privacy - Streamlines permissions settings and advanced controls for Windows 10.
  • winutil - Chris Titus Tech's Windows Utility for installing programs, tweaks, fixes, and updates.

Non-OSS Applications 🛡️

  • O&O ShutUp10++ - Free antispy tool for Windows 10 and 11.
  • O&O AppBuster - Uninstalls store applications and packages.
  • WinReducer-EX - Removes components from WIM/ISO.
  • MSMG ToolKit - Creates a slimmed-down or bloat-free Windows by customizing features.
  • NTLite - Integrates updates, drivers, and removes Windows components from ISO or live installation.
  • Winaero Tweaker - All-in-one app for tuning Windows 7, 8, 10, and 11.
  • WPD - Configures various privacy settings in Windows.

Contributing 🙌

If you find any dead links or issues in this guide, feel free to open an issue and label it appropriately.

If you have a new tool, script, or idea that you'd like to contribute, please open a new issue with the label [Add Label] and provide a description.

We welcome collaborators who want to code with us to improve the repo. Reach out through the issue tracker and let's make Windows more private together!
